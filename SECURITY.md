# Security

Please report a security problem in Mivta or Mivta Niqqud privately to **mivta.ai@gmail.com**, with "Security" in the
subject line. Include the plugin, its version and the steps to reproduce it.

We confirm every report within 3 business days, investigate it, and tell you what we found and when a fix ships.
Please don't open a public issue about a vulnerability before it is fixed.
